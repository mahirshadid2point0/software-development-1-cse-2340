**Software Development 1 - CSE-2340**

This repository contains the course materials, syllabus, lecture
examples, and practical resources for Software Development 1
(CSE-2340).

The repository is maintained as a central resource for students to
access course documents and example code used throughout the semester.

_Course Focus:_
The course introduces students to practical software development
concepts and provides a foundation for building modern software
applications.

_Key areas include:_
1. Software development fundamentals
2. Web development fundamentals
3. HTML and semantic page structure
4. Navigation and hyperlinks
5. Tables and structured content
6. Frontend development concepts
7. Practical coding exercises
8. Version control and GitHub-based workflow
9. Project-oriented learning

_Student Expectations:_
1. Students are encouraged to:
2. Practice coding regularly rather than only before assessments.
3. Understand code instead of simply copying examples.
4. Experiment with different implementations.
5. Use GitHub to maintain their work.
6. Write clean, readable, and maintainable code.
7. Learn how to debug problems independently.
8. Use browser Developer Tools during web development.
9. Ask meaningful technical questions when they are stuck.
10. Build small projects to reinforce concepts.
