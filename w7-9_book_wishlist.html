1. DOM Manipulation

Meaning: JavaScript selects HTML elements and changes what appears on the page.

// Select the place where books will appear
const bookList = document.querySelector("#bookList");

// Create a new HTML element
const card = document.createElement("div");

// Put the book card on the page
bookList.appendChild(card);

In this app, JavaScript creates a card for every book returned by the API.

2. Events and Array Methods

Meaning: Events allow JavaScript to respond when a user clicks or types.

searchButton.addEventListener("click", searchBooks);

Array methods help us work with the returned books:

  • forEach() - display each book.
  • filter() - keep books matching a condition.
  • map() - create a new array, such as an array of book titles.
  • find() - find one particular book.

3. API and Async/Await

Meaning: An API lets our website request information from another service. This project uses the Open Library Search API.

async function searchBooks() {
  try {
    const response = await fetch(apiURL);
    const data = await response.json();

    books = data.docs;
    showBooks();
  } catch (error) {
    message.textContent = "Could not load books.";
  }
}
  • fetch() requests data from the API.
  • async allows us to use await.
  • await waits for the response.
  • try/catch handles errors.

4. Local Storage

Meaning: Local Storage remembers saved books in the browser, even after refreshing the page.

// Save favourite book details
localStorage.setItem("savedBooks", JSON.stringify(savedBooks));

// Read favourite book details
const savedBooks = JSON.parse(
  localStorage.getItem("savedBooks") || "[]"
);

Save a book, click Show Saved, or refresh the browser and click Show Saved again. Your saved book details are stored independently of the latest search.
